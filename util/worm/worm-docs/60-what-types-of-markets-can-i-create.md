# What types of markets can I create?

Source: https://docs.worm.wtf/faq/creating-markets/what-markets-are-supported



You can create any market with an outcome that is objectively verifiable from a publicly accessible source. The AI will only create markets it can also resolve.

Markets that work well include sports results, election outcomes, price milestones, public metrics, and decisions announced via official channels.

Markets that currently cannot be created include anything requiring on-chain data, such as checking wallet balances or token transfers. This is because the AI's resolution system doesn't yet have access to on-chain data sources. This capability is planned for a future update.

If your market idea is declined, it usually means the AI couldn't find a reliable source to resolve it at the deadline. Try specifying a more concrete outcome or a more established source to check against.
