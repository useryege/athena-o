# v21 Managed OO 两页与共用壳视觉方向

模式 Operate。用户已授权第二批八页集中原型设计；本页服务于会员核对 Polygon 提案和争议事件。按现有源码保留字段、权限、分页和解析后果，使用明确合成数据，未完成的真实扫描不得显示成实际成功。当前 React 的手机表格有横向溢出，保留为对照，不改生产源码。

## Direction contract

THESIS：先读事件问题，再核对提出值、时间和参与地址，最后展开完整链上证据。列表用稳定记录层级承载事实，原始 oracle 值不换算为美元或结算结果。

OWN-WORLD：完全沿用 v20 已确认的 Nansen 近黑/深色面板/细边框/白灰文字/mint 关系、Inter 与 JetBrains Mono 分工、224px侧栏和64px顶栏。共有壳继续沿源导航分组与权限过滤；当前模块子项展开，不新增分类。

STORY：确认当前提案或争议页，阅读最新保存的链上事件，按需打开详情核对角色、request/expiration及raw数据。具备写权限的会员可看到单区块解析入口；预览仅模拟结果和区块筛选，不执行链上扫描。

FIRST VIEWPORT：28px标题与次级Refresh位于顶部，下方为Proposals/Disputes页切换和单行解析区域，再下方为事件记录。主阅读列优先显示问题与market入口，block/log、proposed price、request time、proposer/disputer分列；手机重排为问题在前、关键数值与时间两列、完整地址和交易随后，44px操作入口固定可达。详情使用既定右侧抽屉，头尾固定、正文滚动。

FORM：当前实际业务页面向已批准共用世界的普通扩展，code-led；FORM-SEED: not-applicable。没有新视觉世界或图片comp；v20桌面/手机为延续参考，当前React四图为业务与旧布局证据。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

QUALITY BAR：两页每页desktop/mobile/320/200%及详情/只读状态有界检查；原始字符串精度保持，Unknown不写成零；详情可用键盘进入/退出、复制失败可手动复制；所有主操作至少44×44，无整页横向溢出。真实扫描、入库、通知及鉴权不由原型验证。普通扩展不修复既有 DESIGN.md/sidecar 缺失，最终交由独立finish reviewer与documenter记录。
