# v22 Worm Assets 与共享壳方向

模式 Operate。用户批准继续设计 Worm Trading 六页与共用适配，集中审阅。仅静态原型；无生产 UI、真实签名、交易、关闭持仓或凭据操作。

THESIS：先核对选定钱包的资金与连接能力，再阅读持仓和请求，执行动作必须有明确对象与后果。

OWN-WORLD：延续已批准 v20/v21 的 Nansen 单一深色主题、Inter/JetBrains Mono、224px会员侧栏、64px页头与44px控件。保留实际导航分组和权限过滤。

STORY：选定0–20个私有Solana钱包，独立确认余额和Worm连接，阅读持仓/请求；按需进入连接管理、单仓Cash Out或顺序批次核对。

FIRST VIEWPORT：页标题与Refresh，其下Assets/Combinations/Executions；先选定钱包与独立更新状态，再以稳定行列显示SOL、USDC及连接；持仓和请求按任务切换，重要事实直接显示，技术证据按需展开。手机以同一记录层级重排，无整页横向溢出。

FORM：向已确认视觉世界的code-led普通扩展，FORM-SEED: not-applicable。以已批准v21桌面/手机为视觉真值，当前React对照仅验证业务和旧布局。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

QUALITY BAR：六实际页面及共用差异桌面/手机主图、320与200%文字、关键操作可达及原始标识/未知状态检查；读写和结果边界正确。作者一次检查、一批修正、最多一次确认；父任务一次detector、独立finish reviewer和documenter。DESIGN.md/sidecar既有缺失仅记录不修复。
