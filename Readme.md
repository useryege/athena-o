## 二、预测市场方向

### 1. 跨市场套利机器人
polymarket、opinion、赌场三大预测市场的跨市场套利机器人
### 2. 新闻嗅探机器人（消息源关联机器人）
嗅探最新的新闻，并进行分析，然后进行预测，在预测市场进行下注
### 3. 投资者交易记录分析机器人
根据链上交易记录，提取投资者的所有投资数据，对数据进行分析，得出关于某一个投资者综合的投资表现（胜率 利率 盈亏）
### 4. 投资者投资表现综合天梯榜
根据投资者交易记录分析机器人得出的数据，进行综合排名，得出投资者投资表现榜单
### 5. 投资者跟单机器人
根据投资者投资表现综合天梯榜，筛选出最有价值的投资者，进行跟单，实现同买同卖（待测试）
### 6. 预测市场 + TradingView + 策略（产品）
将预测市场的数据进行导出，导入到 TradingView 中进行可视化展示，衔接上用户的策略，实现自动交易
### 7. 预测市场 5/15 分钟市场反转挂单
根据预测市场的数据，专门挂反方向单，等待庄家接手进行接盘

## 三、代币方向

### 1. 钱包代币交易记录分析机器人
根据链上交易记录，提取投资者的所有投资数据，对数据进行分析，得出关于某一个投资者过往所有代币交易综合情况

### 2. 聪明钱包天梯榜
根据钱包代币交易记录分析机器人得出的数据，进行综合排名，得出聪明钱包榜单

### 3. 聪明钱包跟单机器人
根据聪明钱包天梯榜，筛选出最有价值的聪明钱包，进行跟单，实现同买同卖（待测试）

### 4. 代币嗅探机器人
根据链上交易记录，嗅探代币资讯

### 5. 代币合约安全合规审计
根据代币资讯，进行代币合约安全合规审计，得出代币的审计报告
