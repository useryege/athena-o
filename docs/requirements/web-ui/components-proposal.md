## 第一组视觉规则与样板行为

以下视觉参数用于复现已认可截图；其中键盘、校验和本地草稿操作描述样板已检查的行为，不据此新增全站业务交互契约。未展示的悬停／按下效果及专门的键盘焦点图不视为本轮单独确认。

### 表单与按钮

- 标签置于字段上方，使用 v2 的 13px 辅助层级；输入与按钮采用至少 44px 的常规高度，地址继续使用 JetBrains Mono。只读字段降低文字层级但仍可辨认和选择。
- 默认输入框为深色底和清晰的灰色边界；聚焦采用 2px 青绿色轮廓。错误状态采用偏红边界，并在字段下方给出图标与可操作的错误说明。
- 主要按钮继续用 v1 青绿色实心，次要按钮用深色描边。加载示例同时给出图标与动词状态，禁用示例使用深灰底和灰字，不提供悬停活跃感。
- 表单提交失败保留输入并将焦点定位到问题字段；纠正后去掉错误状态。样板只校验地址字符串格式，不声明地址有链上活动或有权访问任何数据。
- 已通过真实键盘导航记录聚焦轮廓，截图作为验证证据；本轮不新增全站每种控件的具体交互契约。

### 状态反馈

所有反馈同时包含图标、标题或正文；状态含义不只依赖颜色。品牌青绿色继续表示主要操作，业务反馈采用以下已确认的 v4 语义色：

| 状态 | 文字／图标 | 背景 | 边框 | 样例 |
| --- | --- | --- | --- | --- |
| 成功 | `#55D9A1` | `#0E201B` | `#2D5747` | 地址格式校验成功 |
| 警告 | `#E6BF72` | `#211C13` | `#665231` | 刷新失败，正在显示旧结果 |
| 错误 | `#F58C9B` | `#24171C` | `#673B47` | 交易明细获取失败，可局部重试 |
| 信息 | `#9BC6F3` | `#141D27` | `#35516D` | 当前支持 Ethereum Mainnet |

这些语义色随本轮 v4 截图获得确认。反馈框保持低饱和度深色背景；正文分别使用同色系浅色，避免在有色背景上依赖对比不足的灰色。普通反馈采用 16px 内边距、12px 圆角，手机样板内边距 14px；完整手机总览尚未单独展示确认。

旧结果样例保留金额、示例钱包、查询范围和原成功获取时间；失败后不清空或更新成当前时间。局部失败样例说明其他成功结果仍可查看，重试入口只对应失败部分。这些信息组织承接[钱包战绩需求](../token/wallet-trading-performance.md)，本轮不改变缓存、旧结果期限或 API 行为。

### 加载与成功空态

- 首次加载显示与代币行相近的骨架，并写明正在加载；不放入假的金额、零值或已成功获取标签。
- 本轮骨架与加载图标静止，已确认静态结构和视觉层级，动画时长与强度留给动效讨论。加载区域标记 `aria-busy`，装饰骨架不作为真实数据朗读。
- 成功空态明确写出当前钱包及最近 30 天没有返回匹配交易，提供调整时间的入口；不将它描述为整个钱包永远没有交易。
- 获取失败、成功无记录、字段缺失和有效零值仍是不同业务事实。样板不演示或重新确认所有空值／金额精度规则，也没有恢复已暂缓的胜率字段。

### 确认弹窗

样例为“放弃本地未保存地址草稿”，仅为了审阅需要保护编辑内容时的确认外观，不意味着钱包查询、刷新或每次切页都新增确认步骤。

- 桌面最大宽度 480px，内容内边距 28px，16px 圆角；近黑遮罩透明度 72%，弹窗使用既有深色面板与清晰边界。
- 标题 20px、正文 16px、辅助说明 13px，沿用 v2；标题、具体影响和动作分开组织。
- “继续编辑”为描边按钮，“放弃草稿”为偏红色实心按钮。默认焦点放在继续编辑，关闭或 Esc 保持草稿；只有点击放弃按钮才重置当前样板输入。
- 手机左右留 20px，正文水平内边距 20px，按钮满宽纵向排列。较高内容允许弹窗内部滚动，不溢出视口。
- 使用原生 modal dialog，使打开期间背景不可操作；关闭后焦点返回打开入口。本次不更改既有业务对确认弹窗的触发条件。

## 验证与真实性

独立 HTML 复用已保存字体、v3 侧栏和顶栏，不访问供应商、账户服务或正式业务路由。导航、重试和时间动作明确提示本地预览；演示草稿仅存于 DOM，不保存到数据库或浏览器存储。没有发送消息、退出账号或修改已保存钱包。

[检查记录](previews/theme-components-v4-checks.json)来自项目 Playwright 配套 Chromium 与 axe：

- 1440px 桌面、390px 手机、320px 窄屏，以及 720px 下根字号放大至 200% 的场景，无整页横向溢出、弹窗溢出、重复 DOM ID、字体加载失败或页面脚本错误。
- 四种场景的初始界面与弹窗均无 axe WCAG 2 A/AA、2.1 AA 自动违规；这不替代完整手动无障碍验收或正式平台验收。
- 无效／有效地址校验、纠正错误、真实 Tab 聚焦、弹窗默认焦点／关闭／Esc／取消保留／本地放弃／回焦均通过。
- 旧结果重试演示不会更改原金额和获取时间；页面没有外部网络请求。200% 是根字号放大模拟，不宣称覆盖所有浏览器原生缩放组合。
- Inter 的通用“使用过多”提示依据用户已确认的 v2 字体选择保留，通过 `hooks ignore-value` 登记仅限本 HTML 的例外；其余检查规则继续生效。

用户已确认本轮展示的视觉效果。[v5 下拉菜单、表格筛选和分页](list-controls-proposal.md)所展示的视觉也已获认可，其他组件继续按范围补齐。v1、v2、v3 原件和确认记录保持不变，正式组件变量、生产行为与主题实施尚未交付。
