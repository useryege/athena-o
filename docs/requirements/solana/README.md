## 目标与已确认范围

ATHENA 在面向 EVM 的 Token 业务之外新增独立 Solana 板块。两者的项目列表、权限和业务状态分开组织。Solana 板块独立不要求单独仓库，也不意味着所有基础设施必须拆开。用户希望先看真实 Solana 新发行样本，再决定研究资料、筛选规则和后续研发方向。

第一步闭环：Solana 发行 → 节点观测 → 保存发行候选及证据 → 补全名称、符号与发行来源 → ATHENA Solana 列表查看。第一步不启动项目研究、活动监听或研究资料刷新调度。

## 第一步的具体行为

- 首版以 Mainnet Beta 上 Token Program 与 Token-2022 成功执行的 InitializeMint / InitializeMint2 为发现事实，包含顶层和 CPI 内部调用。重复铸币不算新发行，失败交易不收录。
- 每个新 Mint 是尚未分类的发行候选，不直接等同于已确认研究项目；NFT、LP 等资产暂不分类，也不只凭精度或供应量排除。平台创建交易内已有买入不影响发现。
- 首次从最新 finalized slot 向前 32 slots 开始扫描，允许配置更早起点。系统持久记录起点和进度，重启继续，读取或解析失败不越过未完成范围。
- 保留 Mint、Token 程序、发行交易、slot、区块时间、发现时间、精度、手续费支付方和初始化时的增发/冻结权限。区块时间缺失标为未知；付费账户不标为创始人。
- 新增和已保存候选均补充链上名称、符号和发行来源。名称/符号支持 Token-2022 自指元数据和 canonical Metaplex Metadata，记录观察 slot 与时间，不抓取链外 URI。没有可用元数据时区分待处理、当前缺失和读取失败。
- 发行来源先识别 Pump.fun、Raydium LaunchLab 和直接 Token 程序初始化，依据初始化交易调用链中的程序、发行指令及具体 Mint 账户。其他来源显示未识别，并保留可确认的直接调用程序；不凭地址后缀、名称或同交易任意程序出现猜测。
- 成员端有独立 Solana 页面、名称/符号/Mint 查询、分页、手动刷新和链上链接。刷新页面只重新读取已保存结果；后台独立持续发现新 Mint，并异步补齐首次信息。名称是发行方自述，可重复、可修改，不代表项目认证。
- 页面展示扫描起点、进度、最近成功时间及故障。无候选、节点错误和没有查看权限分别表达；不以空列表掩盖采集故障。
- 新增独立 Solana READ/NONE 授权，普通账户默认 NONE。管理员账户遵循现有规则，只管理授权，不隐式取得成员业务访问；本地开发会员遵循现有最大权限机制。

尚未购买节点服务或部署自有节点。公共 RPC 是首版可用起点，配额、历史保留与长期容量取决于提供方；不承诺全链全部代币程序覆盖或固定发现延迟。补全失败不阻止新候选入库，缺失和失败可延迟重试，已成功补齐的信息不自动周期刷新。这些重试属于首次信息补全，不是未来研究的每小时活动刷新规则；具体队列和时间约定见[基础信息补全设计](../../design/solana-intelligence/candidate-metadata.md)。

自定义 Token 程序、更多发行协议与品牌归因、链外 metadata/Logo、价格/成交量、评级、交易及主动导入历史存量项目不在本步。补齐系统已发现记录不等于主动导入历史项目。

## 保留的后续业务决定

以下是用户已表达的研究方向，本步不实现：

- 从发行被系统观测到开始研究，项目持续保留研究资格；首次买入、Swap、已交易、长时间没有活动或达到第十天都不自动结束研究。
- 项目有交易或其他被识别的链上活动时触发状态刷新，具体活动清单待定。
- 每个项目分别限频，一小时内三四十次活动最多发起一轮刷新，下一轮至少相隔一小时。不能按自然整点重置；监听频率与研究刷新频率是不同事情。
- EVM Token 的观察期限、活动续期、首次 Swap 停止和停止后冻结规则不套用到 Solana。

首次立即采集、冷却期合并、到期补刷、无活动不重复采集、从刷新开始计时和失败重试语义仍是建议，详见[刷新调度设计](../../design/solana-intelligence/research-lifecycle-and-refresh.md)。不能把这些建议写成已实现或已批准的具体执行规则。

## 第一步验收

两类 Token 程序的直接/CPI 初始化、失败交易排除、真实程序身份、未知字段、版本化交易与缺失数据有解析验证；候选去重、范围原子提交、断点恢复和失败不推进有持久化验证。服务独立构建、启动、停止，API 仅代理并传递可信账户身份，业务服务执行权威 READ 检查。真实主网候选可在独立 ATHENA 页面查询和查看链上证据。

研究持续性、一小时冷却和活动刷新属于后续验收，不是本步交付前置。程序当前暂停是用户的运维决定，不等于废弃后续持续研究方向；本次文档整理不恢复采集。
