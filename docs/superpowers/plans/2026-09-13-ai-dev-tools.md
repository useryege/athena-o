# 第一批 AI 开发工具安装与接入

用户确认：安装并接入五项工具，首轮现有问题仅记录，本次修复接入问题。

## 固定选择

- ShellCheck 0.11.0、grpcurl 1.9.4、govulncheck 1.7.0 安装至项目 dist；发布包校验 SHA256，Go 使用 GOTOOLCHAIN=local。
- PostgreSQL 客户端16通过Ubuntu仓库安装，接受安全补丁更新，不安装数据库服务端。
- @axe-core/playwright 4.13.0 精确开发依赖；沿用 Node 24.14.1、Yarn 1.22.22、Go 1.25.5。
- 不升级其他依赖，不新增CI/MCP插件，不修改业务行为，保留原有未提交改动。

## 实施步骤

1. 复用安装器接入五工具，新增 install-ai-dev-tools、ai-dev-tools-check、lint-shell、vuln-check 四个Make入口。
2. 新增 ui-a11y 独立验收入口，复用隔离运行器与fixtures，覆盖成员列表/添加/取消、管理员状态，桌面/移动、明暗主题、根路径和 /athena。
3. 保存axe原始结果，扫描发现后继续其他场景和前缀，最终失败；现有默认浏览器回归选择不变。
4. 更新安装、工具链和Superpowers指南，说明每个工具何时使用和如何解读扫描结果。

- 首次/重复安装、就绪检查、缺失提示及退出码验证。

- 实际ShellCheck、govulncheck、axe全矩阵首轮扫描，记录发现，不隐藏/忽略/顺手修复原有问题。
- 新增运行器行为测试、默认验收两种前置检查、UI构建，审查本次相对基线差异。
- 完成接入及验证后按仓库要求发送一次中文完成邮件，准确报告扫描发现。
