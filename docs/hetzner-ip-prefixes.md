# Hetzner IPv4 常见前缀

如果你指 IPv4 的前两个数字段，Hetzner 德国服务器没有固定前缀，常见的有：

`5.9.*.*`、`5.75.*.*`、`23.88.*.*`、`46.4.*.*`、`49.12.*.*`、`49.13.*.*`、`78.46.*.*`、`78.47.*.*`、`88.99.*.*`、`88.198.*.*`、`94.130.*.*`、`116.202.*.*`、`116.203.*.*`、`136.243.*.*`、`138.201.*.*`、`144.76.*.*`、`148.251.*.*`、`159.69.*.*`、`162.55.*.*`、`167.235.*.*`、`168.119.*.*`、`176.9.*.*`、`178.63.*.*`、`188.40.*.*`、`195.201.*.*`。

其中较常见的是：`49.12`、`49.13`、`78.46`、`78.47`、`88.99`、`94.130`、`116.202`、`116.203`。

注意，不能只凭前两段确认德国机房，因为 Hetzner 的 AS24940 同时覆盖多个国家，而且 IP 定位库可能不准确。`65.21`、`65.108`、`65.109`、`95.216`、`95.217`、`135.181` 等通常更常见于芬兰机房。[Cloudflare 当前公布的 AS24940 路由](https://radar.cloudflare.com/routing/as24940)；Hetzner 官方建议用 `traceroute`，根据最后几跳中的 `fsn1` 或 `nbg1` 判断德国机房。[Hetzner 数据中心识别说明](https://docs.hetzner.com/general/infrastructure-and-availability/data-centers-and-connection/)
